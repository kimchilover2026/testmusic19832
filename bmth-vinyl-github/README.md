# BMTH Vinyl Player — Spotify Edition

Página web estática con estética oscura, un tocadiscos animado y reproductor oficial de Spotify para **Can You Feel My Heart** de Bring Me The Horizon.

## Publicar en GitHub Pages

1. Creá un repositorio nuevo en GitHub.
2. Subí `index.html` y `README.md` a la raíz del repositorio.
3. Entrá a **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**.
5. Seleccioná la rama `main` y la carpeta `/ (root)`, y guardá.
6. Esperá a que GitHub Pages publique el sitio y abrí la URL que te indique.

## Notas

- Es una web estática: no requiere Node.js, compilación ni claves API.
- El audio lo reproduce el reproductor oficial incrustado de Spotify; las condiciones de reproducción dependen de Spotify y de la cuenta/navegador.
- El vinilo incluye una etiqueta vectorial hecha en SVG con motivos geométricos inspirados en la estética de *Sempiternal*. No necesita archivos de imagen adicionales.
